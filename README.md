# .github

Sfacspace-DAC-Team 조직의 모든 저장소에 공통으로 적용되는 안내와 템플릿입니다.

| 파일 | 하는 일 |
|---|---|
| `CONTRIBUTING.md` | 커밋과 PR 쓰는 법. 자기 안내가 없는 저장소에 보입니다 |
| `pull_request_template.md` | PR 본문 템플릿. 자기 템플릿이 없는 저장소에 쓰입니다 |
| `ISSUE_TEMPLATE/` | 결함 · 기능 이슈 템플릿 |
| `templates/` | 새 저장소에 복사해 넣는 파일(커밋 템플릿, commitlint 설정) |
| `workflow-templates/` | Actions 탭에서 고르는 조직 워크플로 템플릿(PR 제목 검사) |

이 저장소는 조직 공통 템플릿이 동작하도록 공개입니다. 내부 주소 · 고객 이름 · 비밀값을 넣지 않습니다.
