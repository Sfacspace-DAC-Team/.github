# .github

Sfacspace-DAC-Team 조직의 모든 저장소에 공통으로 적용되는 안내와 템플릿입니다.

| 파일 | 하는 일 |
|---|---|
| `CONTRIBUTING.md` | 커밋과 PR 쓰는 법. 자체 안내가 없는 저장소에서 대신 보입니다 |
| `WRITING.md` | 기획 · 설계 · 결정 기록 같은 문서 쓰는 법 |
| `pull_request_template.md` | PR 본문 템플릿. 자체 템플릿이 없는 저장소에 적용됩니다 |
| `ISSUE_TEMPLATE/` | 버그 · 기능 이슈 템플릿 |
| `templates/` | 새 저장소에 복사해 넣는 파일(커밋 템플릿, commitlint 설정, 릴리스 노트 설정) |
| `workflow-templates/` | Actions 탭에서 고르는 조직 워크플로 템플릿(PR 제목 검사) |

조직 공통 템플릿이 동작하려면 이 저장소가 공개여야 합니다. 내부 주소 · 고객 이름 · 비밀값을 넣지 않습니다.
